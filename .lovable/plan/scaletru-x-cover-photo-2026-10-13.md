# Scaletru X cover photo

Create one polished cover image for Scaletru’s X account, using the chosen studio name and short tagline.

## Design
- Near-black background, off-white Manrope-style typography, and restrained electric-lime accents from Scaletru’s identity.
- Exact wording: **SCALETRU** and **We build digital products that scale your business.**
- Preserve the existing custom lime logo from its source image rather than inventing a replacement.
- A clean, spacious composition, with the important wording toward the centre-right and the lower-left clear for X’s profile photo.
- No invented claims, contact details, extra slogans, or project screenshots.

## Deliverable and checks
- Generate a landscape image and finish it at X’s recommended **1500 × 500 pixels**.
- Inspect the wording, logo fidelity, contrast, spacing, and cropping before delivery.
- Save a downloadable cover in Files. No website changes or account updates.

## Technical details
- Use image editing with the existing logo as the reference and a high-quality text-capable image model.
- Keep all important content inside a generous safe area to allow for different X displays.
